## About me

I build reliable Linux-based platforms and automate the path from infrastructure change to secure, observable service delivery.

My work combines systems administration, cloud infrastructure, automation, networking, containerization, observability and security operations. I enjoy turning repetitive operational work into versioned, testable and repeatable workflows.

- Working as a Senior Linux/Unix System Administrator at Digiturk
- Based in Istanbul, Türkiye
- Focused on Linux operations, DevOps, SRE practices and cloud infrastructure automation
- Interested in high availability, platform engineering, infrastructure as code and secure operations

## What I work on

- Linux and Unix systems administration, hardening and performance tuning
- Infrastructure automation with Ansible, Terraform, Bash and PowerShell
- Containerized delivery with Docker and Kubernetes
- Reverse proxy, load balancing and high-availability architectures
- Monitoring, alerting and log platforms with Prometheus, Grafana and Elastic Stack
- Vulnerability, patch and CVE lifecycle automation
- Practical developer and operations tooling with Python and JavaScript
